# 📋 Gerenciador de Tarefas CLI

## Aplicação Interativa em Python - Linha de Comando
Projeto desenvolvido com foco na aplicação de lógica de programação, estruturas de dados dinâmicas e operações de CRUD no terminal.

## 🚀 Sobre o projeto
Este projeto consiste em um sistema interativo de gerenciamento de tarefas via terminal (CLI). A aplicação oferece uma rotina organizada e intuitiva para que o usuário registre seus afazeres, acompanhe o progresso e mantenha suas listas atualizadas em tempo real.

O desenvolvimento foi focado na criação de uma interface de console amigável, com tratamento contínuo de entradas do usuário para evitar quebras de execução, manipulação de coleções estruturadas e feedback visual claro para cada ação executada.

## ✨ Funcionalidades
- ➕ **Cadastro de tarefas**  
Adiciona novas tarefas à lista de pendências com estado inicial não concluído.

- 📋 **Listagem com indicadores visuais**  
Exibição enumerada das tarefas com marcação dinâmica de status ([ ] pendente e [X] concluída).

- ✏️ **Atualização e edição**  
Permite renomear o título de uma tarefa existente a partir do seu número de identificação.

- ✔️ **Conclusão de atividades**  
Altera rapidamente o estado de uma pendência para finalizada.

- 🧹 **Limpeza em lote (List Comprehension)**  
Filtra e remove simultaneamente todas as tarefas que já foram marcadas como concluídas, exibindo a contagem de itens deletados.

- 🛡️ **Tratamento de exceções e validação**  
Proteção contra entradas inválidas (textos em campos numéricos) usando blocos try-except e validação de limites de lista.


## 🛠️ Tecnologias utilizadas
- Python 3
- Estruturas de Dados (Listas & Dicionários)
- List Comprehension & Manipulação de Índices

## 🌐 Acesse o projeto
**Como executar localmente:**

1. Clone o repositório em sua máquina: `git clone https://github.com/devleticiamiranda/gerenciadordetarefas.git`
2. Entre na pasta do projeto: `cd gerenciadordetarefas`
3. Execute o programa com o Python: `python main.py`
